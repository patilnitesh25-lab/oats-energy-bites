# Oats Energy Bites Website
Startup: Healthy Protein Snacks – Oats Energy Bites

## Run locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`.
3. Open Settings → Pages.
4. Select Deploy from a branch → main → /root.
5. Save and copy the generated website URL.
